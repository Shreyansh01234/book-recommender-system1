# 📚 Book Recommender System

A Machine Learning based Book Recommendation System that suggests books to users based on their interests and previous ratings.

## 🚀 Features
- Popularity Based Recommendation
- Collaborative Filtering Recommendation
- User-Friendly Interface
- Dataset driven suggestions

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Flask / Streamlit (if used)
- HTML, CSS (if UI added)
